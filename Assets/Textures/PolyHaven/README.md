# Poly Haven textures

The house materials use these free CC0 assets from Poly Haven:

- Brick Wall 001: https://polyhaven.com/a/brick_wall_001
- Roof Tiles: https://polyhaven.com/a/roof_tiles
- Concrete Floor: https://polyhaven.com/a/concrete_floor

The downloaded 2K diffuse and normal maps are used by the house wall, roof,
foundation, steps, and path materials. Poly Haven publishes these assets under
the CC0 license.
